EviREST

HTTP/REST APIの送信・検証と、テストエビデンス（HTML / Excel）出力を行うChrome拡張機能

機能一覧

リクエスト送信・編集

GET / POST / PUT / PATCH / DELETE / HEAD / OPTIONS / QUERYに対応。クエリ、ヘッダー、JSON・テキスト・フォームのボディを編集でき、cURLコマンドとしてもコピーできます。

CORSの制約を受けない通信

拡張機能の権限で直接通信するため、同一オリジン制約（CORS）を受けず、localhostや社内検証用APIにも直接リクエストが届きます。

環境と変数の切り替え

ローカル、検証、本番などの環境ごとに接続先URL、ポート番号、変数を管理。リクエスト内の${変数名}を自動展開します。

自動アサーション

ステータスコード、レスポンスヘッダー、本文テキスト、JSONパス、応答時間に対する検証ルールを設定し、送信時に合否を判定します。

一括実行とエビデンス出力

選択したリクエストを順次実行し、結果をHTMLレポート（印刷・保存用）やExcelファイル（.xlsx）として出力できます。

ローカル完結のデータ保持

アカウント登録は不要です。設定、履歴、エビデンス、認証情報はすべて利用中のブラウザ内（Storage）にのみ保存されます。

基本操作

1. システムと環境の設定

拡張機能アイコンをクリックして画面を開き、サイドバーの「＋ システムを追加」から対象システムを作成します。環境（ローカル、ステージングなど）に応じたベースURL（例: https://api.example.com）や環境変数を登録します。

2. リクエストの作成と送信

「＋ リクエストを作成」からHTTPメソッドとパスを入力します。URLに /users/${id} のように記載するとパスパラメータ欄が自動で生成されます。ヘッダー、クエリパラメータ、ボディ、認証情報（Bearer / Basic）を設定して「送信」を押します。

3. アサーション（検証条件）の追加

「アサーション」タブで検証条件を設定しておくと、送信時に合否が判定されます。

  • ステータスコードが 200 に等しい
  • JSONパス data.status が success に等しい
  • 応答時間が 500ms より小さい
4. 一括実行とレポート出力

サイドメニューで実行したいリクエストにチェックを入れ、「選択した○件を実行」を押すと順番にリクエストが送信されます。終了後、「HTMLで開く」で印刷・保管用レポートを別タブ表示するか、「Excel出力」でファイルとして保存できます。

よくある質問

Q. アカウント登録やログインは必要ですか？
不要です。インストール後、ブラウザ上でそのまま利用できます。
Q. 入力した認証情報やデータは外部サーバーに送信されますか？
送信されません。リクエスト内容、環境変数、トークン、テスト結果はすべて利用中のPCのブラウザ内（Chrome Storage）にのみ保存されます。通信は利用者が指定したAPI送信先に対してのみ行われます。
Q. localhost や社内ネットワークのAPIもテストできますか？
テストできます。拡張機能の権限で通信を行うため、ブラウザのCORS（クロスオリジン）エラーが発生せず、ローカル開発サーバーや社内APIも直接送信可能です。
Q. エビデンス出力時にトークンなどの機密情報は隠せますか？
HTMLレポートおよびExcel出力では、Authorizationヘッダーなどの認証情報値は自動的に伏せ字（マスク）されます。ただし、リクエスト本文やURLに含まれる機密情報はそのまま出力されるため、外部共有前に内容をご確認ください。
Q. 設定のバックアップや他環境への移行はできますか？
サイドバーのメニューから、システム設定一式をJSONファイルとしてエクスポート・インポートできます。
