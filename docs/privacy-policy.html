EviREST プライバシーポリシー

最終更新日：2026年10月12日

1. データの利用目的

EviREST は、利用者が指定したHTTP/REST APIへのリクエスト送信、レスポンスの検証、テスト結果の記録と出力を行うChrome拡張機能です。

リクエスト、送信先、認証情報、レスポンスは、この機能を提供するためにのみ処理します。広告配信、利用者の追跡、データ販売には一切使用しません。

2. ブラウザ内に保存するデータ

システム・環境の設定、リクエスト、環境変数、トークンやパスワードなどの認証情報、送信履歴、エビデンスと実施者名・備考を、利用者のブラウザ内（Local Storage / Chrome Storage）に保存します。送信履歴にはリクエスト内容を保存し、エビデンスにはリクエスト・レスポンスの内容を記録します。

開発者のサーバーへの送信やクラウド同期は一切行いません。独自の暗号化やパスワードによる保護は行っていないため、機密情報を入力する場合はPCとブラウザのアクセス管理にご注意ください。

3. 通信先

送信操作を行うと、URL、ヘッダー、認証情報、ボディを、利用者が明示的に指定したAPIへ送信します。リダイレクトがある場合はブラウザの通信処理に従って移動先へ接続します。API側でのデータの扱いは、その送信先の方針に従います。

拡張機能から開発者へのアクセス解析・利用状況・エラー情報の送信は行いません。閲覧中のWebページやブラウザの閲覧履歴を収集する機能はありません。

4. ファイルとクリップボード

インポートでは、利用者が選択したJSONファイルや貼り付けた内容を読み込みます。エクスポートでは、設定やテスト結果を利用者の操作でファイルに保存、またはHTMLレポートとして別タブに表示します。

コピー操作では、利用者が選択したcURLコマンド、レスポンス本文、AI用プロンプトをクリップボードへ書き込みます。クリップボードを自動で読み取る機能はありません。AI用プロンプトを外部AIサービスへ自動送信する機能もありません。

エクスポートした設定には認証情報が含まれる場合があります。レポートの伏せ字は認証情報を含むヘッダー値が対象で、URLや本文の機密情報は自動で除去しません。外部と共有する前に内容をご確認ください。

5. データの保持と削除

保存データは、利用者が削除するまでブラウザ内に保持されます。履歴やエビデンスは画面から随時削除できます。

拡張機能をアンインストールすると、拡張機能に関連するブラウザ内保存データもすべて削除されます。エクスポート済みのファイルや、API側に送信済みのデータは削除されません。

6. 第三者への提供

開発者によるユーザーデータの第三者への販売、広告目的の提供は一切行いません。

EviREST のユーザーデータの利用は、Limited Use（限定使用）の要件を含むChrome Web Store User Data Policyに厳格に従います。

7. ポリシーの変更と問い合わせ

機能やデータの扱いを変更する場合は、本ページを更新します。
